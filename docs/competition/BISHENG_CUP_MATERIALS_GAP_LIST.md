# 毕昇杯初赛材料缺口清单

## P0：提交前必须补齐

- [ ] 下载并使用赛区最新统一设计报告模板；
- [ ] 核对题目、学校、院系、4 名学生、指导教师数量和联系方式；
- [ ] 补硬件 BOM、接口接线图、系统框图和数据流图；
- [ ] 以本次运行重新采集 HDMI、扫码枪、摄像头、音频和支付证据；
- [ ] 对 10-SKU manifest、SQLite 商品价格和演示脚本做一次一致性核对；
- [ ] 在干净环境安装依赖并运行最小 API smoke test；
- [ ] 对最终提交目录做私钥、token、数据库、个人信息和旧公网地址扫描；
- [ ] 给提交包生成版本号、文件清单和 SHA-256。

## P1：答辩前补强

- [ ] 将现有历史报告筛选为一套日期一致的证据；
- [ ] 补一段 3--4 分钟连续演示视频；
- [ ] 补失败场景：未知条码、断网、摄像头忙和音频不可用；
- [ ] 填写真实硬件采购价，避免只写“低成本”而无依据；
- [ ] 为视觉模型提供固定测试集、失败样例和延迟表。

## 不能写进初赛材料的表述

- “Top-3 识别率 100%，因此实际场景准确率 100%”；
- “已接入真实微信/支付宝支付”，如果实际只是演示支付页和模拟按钮；
- “电脑只是显示器”，如果现场仍依赖电脑提供服务或网络；
- “进程运行即代表 HDMI 已显示”；
- “已覆盖所有商品/所有光照”，如果数据集仍为低样本。
