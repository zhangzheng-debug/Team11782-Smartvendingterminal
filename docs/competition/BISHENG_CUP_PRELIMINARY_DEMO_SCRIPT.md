# 毕昇杯初赛 4 分钟演示脚本

## 0. 演示前（不计时）

- 确认 HDMI 已显示 QML 收银台；
- 确认扫码枪插入已验证 USB Host 口；
- 确认摄像头、音频设备和电源连接；
- 若云支付不可用，提前选择本地/局域网 fallback，不在现场临时修改代码；
- 购物车使用演示重置策略，不能把历史订单当作新证据。

## 1. 作品定位（30 秒）

> 这是运行在嵌入式 Linux 板端的自助收银终端。扫码枪负责确定性计费，端侧 RKNN/NPU 视觉模型负责扫码后的商品一致性校验和未知条码候选。视觉不会连续自动加购，所以识别错误不会直接造成重复收费。

## 2. 扫码与计价（50 秒）

1. 扫描或输入 SKU001；
2. 指出商品名、单价、数量和总价刷新；
3. 再输入 SKU002；
4. 说明商品主数据来自 manifest/SQLite，业务链路不依赖电脑浏览器。

## 3. 拍照与视觉校验（60 秒）

1. 点击拍照，展示预览、Top-3、参考分和延迟；
2. 说明 `active_backend=rknn_cli` 时走板端 RKNN/NPU，异常时保留 ONNX fallback；
3. 强调视觉结果只做校验/候选，不自动再次加入购物车；
4. 输入未知条码，展示“未录入商品”和候选提示，说明不会静默计费。

## 4. 语音与可靠性（40 秒）

1. 输入或说“一共多少钱”；
2. 展示屏幕状态和中文播报；
3. 展示拍照连续触发时的忙/冷却提示；
4. 简述失败状态会被显示，不以进程存在冒充 HDMI 可见。

## 5. 结账与支付边界（50 秒）

1. 点击结账，展示本地订单、二维码和支付状态；
2. 网络正常时展示**仿真云支付**手机页和 `paid` 回写；
3. 网络不可用时展示本地/局域网 fallback；
4. 明确说明这不是已经接入真实微信/支付宝商户结算。

## 6. 收束（10 秒）

> 本作品的核心不是把视觉识别强行变成计费，而是让可靠条码、端侧 AI 校验、故障可解释和本机闭环同时成立。当前视觉结果属于小样本 baseline，后续将扩充数据并做更严格的现场泛化测试。
