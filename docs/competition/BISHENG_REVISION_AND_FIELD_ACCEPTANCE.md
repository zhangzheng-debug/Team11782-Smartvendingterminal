# 毕昇杯初赛修订说明与现场验收

## 本轮改动

本轮按组委会提供的五章提纲重排设计论文，题目统一为“基于嵌入式系统的条码及端侧视觉校验的自助收银终端”，补齐四名参赛成员和指导教师信息，并将原稿中的技术描述改为可核验的工程口径。论文明确区分了历史板端证据、本次 Windows 隔离测试和待现场复测项目。

应用层只修复未知条码的视觉候选入口：`capture=true` 时强制获取新照片；拍照忙、冷却、超时、缺文件、模型不可用或预测失败时返回明确失败，不复用上一件商品的旧图，也不自动加购。已知条码的计费路径、购物车、支付和数据库结构没有改动。

测试替换了摄像头、推理和音频设备调用，结果证明应用分支和 QML `submitScan` 参数/反馈逻辑正确；不等同于本次已经在开发板上重新完成相机、RKNN、HDMI 或 HID 现场验收。

## 现场验收顺序

1. 记录版本、日期、屏幕分辨率、USB 端口和网络拓扑。
2. 启动 `/userdata/start_retail_hdmi_qml.sh`，确认 HDMI 画面肉眼可见。
3. 放置商品 A，扫码已知 SKU，确认购物车只增加一次。
4. 放置商品 B，扫描未录入条码，确认界面显示未录入，不增加购物车。
5. 确认未知条码分支得到 B 的新照片和候选；不能显示 A 的历史照片结果。
6. 在摄像头忙、冷却、拔摄像头或模型不可用时，确认有明确错误，且不产生候选加购。
7. 人工核对快捷商品后只点击一次加入购物车，再验证删除、清空和结账。
8. 网络可用时验证仿真支付；网络不可用时记录 `local_debug`/未支付，不写成真实支付成功。
9. 保存 HDMI、扫码枪、摄像头、音频、手机支付页、日志和订单编号证据。
