# 模型产物说明

公开仓库保留板端部署所需的精简 RKNN/ONNX 入口和类别映射；原始训练图片、训练缓存、完整 Qt runtime 和现场数据库不进入仓库。提交给赛区的完整材料可以另行包含模型文件，但必须同步提供 SHA-256 和来源说明。

## 运行路径

- 主视觉路径：板端 RKNN CLI/NPU 后端。
- 兼容路径：ONNX Runtime fallback。
- 业务策略：视觉只做扫码后的辅助校验或未知条码候选，不自动连续加购。

## 复现所需材料

训练或部署时需要补齐：

1. 10-SKU 脱敏 `manifest.csv`；
2. 每类图片数量、训练/验证划分和增强配置；
3. ONNX 导出日志；
4. RKNN 转换配置、量化数据集说明和目标芯片版本；
5. Top-1/Top-3、延迟、失败样例和模型 SHA-256。

本工作区的 10-SKU baseline 记录在 `TRAINING_REPORT_V260_YOLOV8N_CLS.md` 和 `EVALUATION_REPORT_V260.md`：117 张图、固定 18 张测试图，Top-1 94.44%、Top-3 100%。这是小样本流程验证，不是商用准确率承诺。模型文件应通过比赛提交包或受控制品存储分发，不要把私有数据和未授权商品图片直接公开。
